🎯 PROBLEM & SOLUTION

Why We Built This Platform

Replacing fragmented multi-tab spreadsheets with a single governed financial database.

❌ The Challenge with Legacy Spreadsheets
  • • Broken formulas, mismatched currency conversions (INR, BDT, IDR, NPR to USD).
  • • No role security: Department heads could accidentally overwrite global overheads or other entities.
  • • Painful donor & geographic reporting: Inability to pivot by CIFF, Mulago, Location, or Program stream.
  • • Disconnected personnel master data vs. payroll budget line items.
✅ The Centralized Solution
  • ✓ Standardized Chart of Accounts (COA) mapped to unified GL codes.
  • ✓ Role-Based Access Control (RBAC): Entity and department-level data isolation.
  • ✓ Automated Employee Master integration with CTC, banding, and increments.
  • ✓ Built-in 5D tagging (Location, Donor, Activity, Condition Area, Department).

🛠️ DEVELOPMENT JOURNEY

Steps & Key Challenges Faced During Creation

How we architected the platform and solved complex multi-entity financial engineering challenges.

🔨 Key Implementation Steps
  • 1. Global Architecture & Multi-Currency Setup: Modeled 6 legal entities, 24 departments, and standard conversion matrices (USD, INR, BDT, IDR, NPR).
  • 2. Standardized Chart of Accounts (COA): Established uniform GL codes and parent account groupings across all entities.
  • 3. Bottom-Up Estimation Engines: Built automated employee sync with increment modeling, travel unit cost calculators, and IMP workshop logs.
  • 4. 5D Tagging Framework: Embedded Location, Donor, Activity, Condition Area, and Department dimensions on every line item.
  • 5. Security & Role-Based Access Control: Enforced strict entity-level data isolation to protect confidential personnel data.
  • 6. Excel Export Engine: Created dimension-specific clean sheets, granular input sheets, and the consolidated 5D Master Matrix.
🧗 Key Challenges Faced & Overcome
  • • Multi-Currency Phasing Precision: Converting 5 native currencies to USD across 12 monthly columns without rounding errors. (Solved via unified financial normalization utilities).
  • • Entity Isolation vs Global Rollup: Preventing local users from viewing confidential payroll of other country offices while giving leadership instant global consolidation. (Solved via role-aware middleware).
  • • 5D Matrix Tagging vs Accounting GL: Enabling grant/donor slicing without breaking standard statutory accounting structures. (Solved via unified 5D schema).
  • • Clean Dimension-Specific Excel Workbooks: Formatting reports so single-dimension sheets remain uncluttered while retaining the 5D master matrix and input details in one click.
